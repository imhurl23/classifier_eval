# First-wave held-out analysis plan — draft awaiting audit and freeze

The first wave retains all 2,487 eligible original paired test conversations and quarantines the seven pairs exposed in development. There is no provisional 1,200-token cutoff and no silent truncation. Every scheduled request must fit its verified serving context including output reserve. If that cannot be achieved, revise and freeze a clearly labeled coverage cohort before any test inference; retain the unsupported cohort for separate reporting.

The common-policy primary comparison uses binary interaction harmfulness with the approved long rubric. Seven hosted arms, Tev1, its Qwen letter base, the optional Qwen JSON interface, and Safeguard are planned. Granite BYOC and Qwen3Guard/Nemotron native-policy derived-OR interaction judgments are separate comparators. PolicyLM is a separate local User-only supplement with documented source-exposure limitations; Aegis interaction gold is not prompt gold.

Report strict binary agreement and macro F1 per source first. Refusals, invalid outputs, truncations, and API errors count as strict failures; also report their separate rates. Missing planned outputs remain visible in coverage, with a strict full-denominator sensitivity analysis. Report unsafe recall, safe false-unsafe rate, and confusion tables. Native needs_caution remains explicit, with predeclared safe/unsafe/excluded collapse sensitivities. No missing or nonhuman multiclass/turn labels are manufactured.

For paired arm differences, resample conversation IDs together, stratified by source and source binary label (5,000 bootstrap draws, seed 20261007). Report effect sizes and nominal 95% intervals. Paired binary t-tests are exploratory with Holm correction over all scheduled common-policy pairwise comparisons; exact McNemar tests are a separate binary sensitivity family. Do not interpret a nonsignificant difference as equivalence.

Fit a source-agreement logistic random-intercept model with arm, source, source safe/unsafe label and centered log conversation characters as fixed effects, grouped by item. The arm-by-source-label interaction is an exploratory extension. Verify numerical convergence and integration accuracy. Model effects describe these systems on these data; no architecture causal claim follows. Fit a separate log end-to-end latency random-intercept model; keep native shared-call and derived-decision timings separate. Adjust model-versus-Jev contrasts with Holm within each specified model family; omnibus tests and intervals are nominal and labeled exploratory. Add source interactions only as separately labeled exploratory analyses.

The single-reviewer development audit is finalized before prompts and this plan are frozen. Its judgments assess study-policy alignment separately from source-label agreement. Inter-rater agreement is unmeasured. A later held-out audit must keep random and disagreement-enriched components separate. Test findings must not be used to tune prompts for this held-out evaluation.

Expansion to additional schemes, rubrics, companions, controls or arms requires a separately frozen wave with explicit physical-call counts and budget. Once these held-out outcomes are examined, subsequent tuning needs a fresh untouched test set. This draft is not a completed or externally timestamped preregistration.
